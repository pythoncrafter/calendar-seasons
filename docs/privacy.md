# Privacy policy

Calendar Seasons stores theme preferences using the browser extension's local storage. It does not collect, read, transmit, or change event titles, descriptions, attendees, account details, or calendar data. It does not use analytics, advertisements, cookies, a backend, native messaging, or remote executable code. All decorative assets and code ship inside the extension.

The extension asks for storage and access to `https://calendar.google.com/*` so it can apply appearance settings. No other websites are requested. Chrome and Safari have independent local settings. Removing the extension removes its browser-managed preferences according to the browser's normal lifecycle.

The containing iOS app displays setup instructions and opens a Google Calendar URL in the user's default browser. Google handles its own account sign-in and calendar service under its own privacy policy. Calendar Seasons has no affiliation with Google or Apple.

The included Apple privacy manifests declare no tracking, no collected data, and no accessed required-reason APIs. Confirm these declarations against the final compiled binary during release review. Before publication, host this policy at a stable public URL and add the publisher's real name and support contact. No publisher identity has been invented in this repository.
